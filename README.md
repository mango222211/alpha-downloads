## v2.3 설치 및 업데이트

- **Windows 10/11 x64:** [설치 프로그램 다운로드](https://github.com/mango222211/alpha-downloads/releases/download/v2.3.0/Alpha-AI-2.3.0-Setup-x64.exe). Setup.exe를 실행하고 설치 마법사를 완료하세요. 필요한 파일 전체와 바탕화면·시작 메뉴 바로가기를 설치합니다. 압축 해제나 PowerShell 명령은 필요하지 않습니다.
- **macOS:** CPU에 맞는 Apple Silicon 또는 Intel용 ZIP을 풀고 Alpha AI.app을 응용 프로그램에 넣으세요.
- **업데이트:** 기존 Alpha를 메뉴 막대 또는 시스템 트레이에서 완전히 종료한 뒤 새 버전을 설치하세요. 로그인·설정 데이터는 보존합니다. 이전 포터블 폴더는 자동 삭제하지 않습니다.
- **Windows 제거:** Windows 설정 → 앱 → 설치된 앱 → Alpha AI에서 제거할 수 있습니다.

v1.8 이상 Windows 업데이트 다운로드는 Setup.exe를 제공합니다. v1.5–1.7의 ZIP 전용 업데이트에는 Setup.exe와 설치 안내가 담긴 호환 ZIP을 제공합니다. v1.4 이하 앱은 최신 배포본을 한 번 직접 설치해야 업데이트 확인 기능을 사용할 수 있습니다. 새 버전 확인과 다운로드를 지원하며 설치는 사용자가 진행합니다. AI 대화는 운영자의 서버가 켜져 있어야 합니다.

## 검증 범위

Python 59개와 Node 124개 검사, 설치 파일 내부 77개 앱 파일의 무결성과 제거 프로그램 포함 여부, 구버전 업데이트 호환성을 확인했습니다. Windows 실제 기기의 설치·업데이트·제거는 아직 확인하지 못했습니다.

현재 개발용 미서명 배포본으로 Windows 코드 서명 및 macOS Developer ID 서명·공증은 적용되지 않았습니다.

## v2.1 서버 이미지 이해
사용자 PC에는 Ollama·이미지 모델 설치가 필요하지 않습니다. 질문 시 최신 화면 한 장을 Alpha 서버로 보내 분석합니다. 전송 동의를 받은 뒤 처리하며, 앱 서버는 화면 원본을 파일·대화 DB에 저장하지 않습니다. 분석 설명은 대화에 남고 이미지 추론 토큰도 집계됩니다. 전체 화면 캡처는 데스크톱 앱에서 지원합니다.

## v2.1 모니터 해상도 자동 추천
화면 공유 허용 후 실제 캡처 영상의 가로 × 세로 px를 감지하여 추천 기본값으로 표시합니다. 고정 1280×720 전송 축소를 제거하고 원본 해상도(최대 8K 범위)와 JPEG 품질 90%로 전송합니다. 앱·다이나믹·앱 내부 웹 설정에 함께 적용됩니다. 4K·8K 합성 화면의 실제 서버 모델 분석을 확인했습니다. 더 높은 해상도는 전송량·처리 시간·토큰 사용을 늘릴 수 있으며, 모델 내부에서도 이미지가 조정될 수 있습니다. 정확도가 보장되는 것은 아닙니다.

## v2.2 다이나믹 위치 잠금
앱 설정과 앱 안 대화 화면의 설정에서 ‘다이나믹 위치 잠금’을 켜고 끌 수 있습니다. 켜면 드래그와 위치 선택을 막고 즉시 자동 저장합니다. 앱을 종료했다가 다시 실행해도 잠금이 유지됩니다. 대화 펼치기·접기와 라이브 중 가로 확장은 계속 사용할 수 있습니다. 일반 웹 브라우저에는 데스크톱 위치 잠금이 표시되지 않습니다.

## v2.3 다이나믹 뒤 화면 읽기
Windows 10 2004 이상·Windows 11에서는 라이브 중 다이나믹 창을 캡처에서 제외합니다. Mac에서는 질문 시 선택한 모니터를 새로 캡처하면서 Alpha의 다이나믹·라이브 테두리·라이브 미리보기 창을 제외합니다. 이미지와 글자 인식에 적용됩니다. Mac 녹화 미리보기와 저장 영상에는 다이나믹이 보일 수 있습니다.

기존 화면 기록 권한과 전송 동의가 필요합니다. 라이브 중지·공유 설정 변경 시 진행 중인 캡처를 취소하며, 실패한 캡처를 오래된 이미지로 대신하지 않습니다. 선택한 모니터 ID를 확인할 수 없으면 다른 모니터를 대신 읽지 않습니다.

캡처·권한·취소 자동 검사와 Mac 네이티브 도구의 arm64·x64 컴파일은 완료했습니다. 이 실행 환경에는 화면 캡처 권한이 없어 실제 화면의 가림 제거는 직접 검증하지 못했습니다. Windows 실제 기기 확인도 남아 있습니다.
