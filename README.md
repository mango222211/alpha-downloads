# Alpha AI 다운로드

[앱 다운로드 페이지](https://mango222211.github.io/alpha-downloads/) · [릴리스](https://github.com/mango222211/alpha-downloads/releases/tag/v1.1.0) · [웹에서 대화](https://spent-undiluted-spring.ngrok-free.dev/)

이 저장소에는 공개 앱 ZIP과 설치 안내만 있습니다. 서버 개발 소스와 계정 데이터는 포함하지 않습니다.

macOS는 ZIP을 풀고 Alpha AI.app을 응용 프로그램에 넣으세요. Windows는 폴더 전체를 풀고 Alpha AI.exe를 실행하세요. 업데이트 전에는 기존 Alpha를 완전히 종료하세요.

앱 다운로드는 서버가 꺼져 있어도 가능하지만 AI 대화는 운영자 서버가 켜져 있어야 합니다. 현재 개발용 빌드로 macOS Developer ID 서명·공증과 Windows 코드 서명은 적용되지 않았습니다.

## 실행 문제 확인 중

기존 ZIP은 정식 서명 없는 개발용 파일입니다. Mac은 Developer ID 서명·공증 전이어서 보안 차단이 발생할 수 있습니다. Windows 11의 시작 무반응은 아직 원인을 확인하고 있습니다.

[Windows 1.1.1 진단 미리보기](https://github.com/mango222211/alpha-downloads/releases/tag/v1.1.1-diagnostic)를 모두 압축 해제한 뒤 Start-Alpha-Diagnostics.cmd를 실행하면 시작 오류와 종료 코드를 확인할 수 있습니다. 이 파일도 정식 서명은 없으며 Windows 실제 기기 실행 검증 전입니다. 일반 설치 프로그램이 아닙니다.
