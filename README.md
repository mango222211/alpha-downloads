## v1.5 설치 및 업데이트

macOS는 Apple Silicon 또는 Intel용 ZIP을 풀고 Alpha AI.app을 응용 프로그램에 넣으세요. Windows x64는 폴더 전체를 풀고 Alpha AI.exe를 실행하세요. 설치 프로그램이 아닌 포터블 앱입니다. 업데이트 전에는 기존 Alpha를 완전히 종료하세요.

기존 구버전은 v1.5를 한 번 직접 설치해야 새 버전 확인 기능을 사용할 수 있습니다. v1.5부터 업데이트를 자동 확인하고 검증된 ZIP을 다운로드할 수 있습니다. 앱 교체는 직접 진행해야 합니다.

AI 대화는 운영자 서버가 켜져 있어야 합니다.

## 실행 제한

현재 개발용 빌드로 macOS Developer ID 서명·공증과 Windows 코드 서명은 적용되지 않았습니다. 운영체제에서 실행이 제한될 수 있으며 Windows 실기기 실행 검증은 완료되지 않았습니다.
