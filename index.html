v2.6 · Mac 교체 설치·화면 권한 안내

Mac은 .pkg 설치 프로그램으로 응용 프로그램의 Alpha AI를 교체합니다. Windows는 Setup.exe로 업데이트합니다. 기존 앱을 먼저 삭제할 필요가 없으며 로그인·설정 데이터는 유지합니다.

화면 목록 요청 중복을 제거하고 권한 거부·응답 지연·모니터 없음 오류를 구분했습니다. 라이브 연결 창에 실행 버전, 권한 설정과 앱 재시작 버튼을 추가했습니다.

macOS에서 권한이 거부되면 화면 기록을 허용한 뒤 앱을 재시작해야 합니다. 이미 허용되어 있다면 스위치를 껐다 켜 승인을 갱신하세요. 개발용 미서명 빌드이므로 업데이트 후 권한 재승인이 필요할 수 있습니다.

자동 검사와 설치 파일 구성을 검증했습니다. 실제 사용자 화면 캡처와 Windows 설치 실행은 이 빌드 환경에서 확인하지 못했습니다.

설치 방법

  • Windows: 다운로드한 Setup.exe를 열고 설치 마법사를 완료하세요. 설치 후 바탕화면 또는 시작 메뉴의 Alpha AI로 실행합니다. 압축 해제나 PowerShell 명령은 필요하지 않습니다.
  • macOS: .pkg를 실행하면 /Applications/Alpha AI.app을 설치·교체합니다. 설치 후 응용 프로그램의 Alpha AI를 여세요.
  • 업데이트: 메뉴 막대 또는 시스템 트레이에서 Alpha를 완전히 종료한 뒤 새 버전을 설치하세요. 기존 앱 삭제는 필요하지 않습니다. 로그인·설정 데이터는 보존합니다. 다운로드 폴더의 구버전 대신 응용 프로그램 또는 시작 메뉴에서 실행하세요.
  • Windows 제거: Windows 설정 → 앱 → 설치된 앱 → Alpha AI에서 제거할 수 있습니다.

화면 공유

라이브와 화면 내용 포함을 켜고 전송 안내에 동의하면 질문할 때 최신 화면 한 장을 Alpha 서버로 보냅니다. 원본 이미지는 앱 서버의 파일·대화 DB에 저장하지 않으며 분석 설명은 대화에 남습니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

전체 화면 캡처는 데스크톱 앱에서 지원합니다. 운영자 서버 연결과 운영체제 화면 권한이 필요하며, 화면 공유를 끄면 전송이 중지됩니다.

이용 안내

앱 다운로드는 언제든 가능합니다. AI 대화는 운영자의 서버가 켜져 있을 때 이용할 수 있습니다.

현재 개발용 빌드이며 macOS 정식 배포 서명·공증과 Windows 코드 서명은 적용되지 않았습니다. 설치 파일의 구성·무결성 검사는 완료했으며, Windows 실제 기기의 설치·업데이트·제거 확인은 아직 남아 있습니다.

이 페이지는 앱 배포와 이용 안내만 제공합니다. 서버 개발 소스는 비공개로 관리됩니다.
