v4.8.0 업데이트

유료·활성 1개월 무료체험 계정에 파일 찾기를 제공합니다. 허용한 폴더에서 파일을 찾아 Finder·탐색기에 표시하고 작업 방법을 함께 안내합니다.

  • 앱·다이나믹에서 폴더 접근 허용 후 파일 이름 검색
  • 선택 파일 위치 표시와 삭제·이동 방법 안내
  • AI 안내용 파일 이름·상대 위치 전송은 별도 승인
  • 파일 내용·절대 경로 미전송, 권한 철회 및 만료 계정 차단
  • 삭제·이동·파일 실행은 자동 수행하지 않음

화면 분석 기반 승인 검색, 유료·무료체험 검색 결과 최대 7개, 다이나믹 닫힘 애니메이션도 유지합니다.

설치 방법

  • Windows: 다운로드한 Setup.exe를 열고 설치 마법사를 완료하세요. 설치 후 바탕화면 또는 시작 메뉴의 Alpha AI로 실행합니다. 압축 해제나 PowerShell 명령은 필요하지 않습니다.
  • macOS: .pkg를 실행하면 /Applications/Alpha AI.app을 설치·교체합니다. 설치 후 응용 프로그램의 Alpha AI를 여세요.
  • 업데이트: 메뉴 막대 또는 시스템 트레이에서 Alpha를 완전히 종료한 뒤 새 버전을 설치하세요. 기존 앱 삭제는 필요하지 않습니다. 로그인·설정 데이터는 보존합니다. 다운로드 폴더의 구버전 대신 응용 프로그램 또는 시작 메뉴에서 실행하세요.
  • Windows 제거: Windows 설정 → 앱 → 설치된 앱 → Alpha AI에서 제거할 수 있습니다.

파일 찾기 권한

데스크톱 앱의 유료·활성 무료체험 계정에서 사용할 수 있습니다. 사용자가 선택하고 별도로 허용한 폴더 안의 파일 이름·크기·수정 시각만 이 기기에서 검색합니다. 숨김 항목·심볼릭 링크는 제외하며, 검색 범위와 결과 수는 제한됩니다. 폴더 권한은 앱 실행·로그인 세션 범위이며 파일 찾기 창에서 철회할 수 있습니다.

표시하고 AI 안내를 선택하면 전송 대상을 다시 확인받습니다. 동의한 선택 파일의 이름·상대 위치·운영체제·표시 요청 상태만 대화에 저장하며, 파일 내용과 절대 경로는 보내지 않습니다. 파일 이름에도 민감한 정보가 있을 수 있으므로 동의 전에 확인하세요. 실제 파일 삭제·이동·실행 권한은 포함하지 않습니다.

화면 공유와 검색

라이브 관찰 또는 스크린샷 기능은 화면 공유 동의와 운영체제 권한이 필요합니다. 질문과 함께 선택한 화면 자료를 Alpha 서버로 보내 분석합니다. 원본 이미지는 앱 서버의 파일·대화 DB에 저장하지 않으며 분석 설명은 대화에 남습니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

화면 분석 후 공개 제품명·오류·증상으로 관련 검색어를 생성합니다. 기본값인 승인 검토에서는 검색어와 제공업체를 확인하고 이번 검색을 허가할 수 있습니다. 승인 무조건 허가는 별도 확인 후 저장되며 화면 분석 기반 검색에만 적용됩니다. 승인된 검색어는 검색 제공업체로 전송됩니다. 민감 정보 필터가 모든 정보를 완벽하게 탐지하지는 못하므로 검색어를 확인하세요.

전체 화면 캡처는 데스크톱 앱에서 지원합니다. 운영자 서버 연결과 운영체제 화면 권한이 필요하며, 화면 공유를 끄면 전송이 중지됩니다.

이용 안내

앱 다운로드는 언제든 가능합니다. AI 대화는 운영자의 서버가 켜져 있을 때 이용할 수 있습니다.

현재 개발용 빌드이며 macOS 정식 배포 서명·공증과 Windows 코드 서명은 적용되지 않았습니다. Windows 및 Intel 실제 기기의 설치·업데이트·제거 확인은 아직 남아 있습니다.

이 페이지는 앱 배포와 이용 안내만 제공합니다. 서버 개발 소스는 비공개로 관리됩니다.
