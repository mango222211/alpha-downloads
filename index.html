v1.7 · 전체 화면 라이브 오류 수정

새 버전 확인과 검증된 업데이트 파일 다운로드를 지원합니다. 기존 구버전 사용자는 v1.7를 한 번 직접 설치해야 합니다. 이후에도 다운로드한 앱 교체는 직접 진행합니다.

창 공유를 제거하고 모니터 전체 화면만 연결합니다. 전체 화면을 창으로 잘못 판정하던 오류를 수정했습니다. Mac의 화면 기록 권한이 앱에 거부로 전달되는 경우 권한 재등록이 필요할 수 있습니다. Windows 실기기 캡처는 미검증입니다.

설치 방법

  • Mac: ZIP을 풀고 Alpha AI.app을 응용 프로그램 폴더에 넣으세요.
  • Windows: 폴더 전체를 압축 해제한 뒤 Alpha AI.exe를 실행하세요. 설치 프로그램이 아니므로 설치 완료 안내는 나오지 않습니다.
  • 업데이트 전에는 메뉴 막대 또는 시스템 트레이에서 기존 Alpha를 완전히 종료하세요.

이용 안내

앱 다운로드는 언제든 가능합니다. AI 대화는 운영자의 서버가 켜져 있을 때 이용할 수 있습니다.

현재 개발용 빌드이며 macOS 정식 배포 서명·공증과 Windows 코드 서명은 적용되지 않았습니다. Windows 실제 기기 실행 검증은 별도로 필요합니다.

이 페이지는 앱 배포와 이용 안내만 제공합니다. 서버 개발 소스는 비공개로 관리됩니다.
