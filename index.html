4.15.9 업데이트

Windows 글자 입력이 4.15.8 뒤에도 들어가지 않던 문제의 보강입니다(앱 쪽 desktop/native/input.ps1, desktop/control.cjs; 서버 변경 없음).

Windows 입력: 대상 창을 지정해 활성화하고, 들어갔는지 확인한 뒤 최대 10회 재시도 (사용자 결정 2026-10-12)

  • 경위: 허가 창이 뜨는 동안 Alpha 가 포그라운드가 되어 글자가 대상 앱(메모장)에 가지 않았습니다. 4.15.8 은 "Alpha 가 아닌 맨 앞 창"을 앞으로 가져오게 했지만 Windows 가 포그라운드 전환을 거부하거나 다른 창이 앞에 있으면 여전히 들어가지 않을 수 있었습니다.
  • 앱(control.cjs): Windows 에서 type 요청에 마지막으로 읽은 앞 앱의 프로세스 이름(frontApp, 예: Notepad)을 activate 로 함께 보내 도우미가 그 앱을 지정해 앞으로 가져옵니다. 시도 횟수·검증 결과를 조작 기록(typed 이벤트)에 남깁니다.
  • 도우미(input.ps1):
  • Bring-Front: SetForegroundWindow 가 거부되면 Alt 키를 한 번 눌렀다 떼고 다시 시도합니다.
  • Do-Type: 입력 전 대상 활성화 → 포그라운드가 Alpha 면 건너뛰고 재시도 → 입력 → UI Automation 으로 포커스된 편집 요소의 글자를 읽어 실제로 들어갔는지 확인. 사용자 클릭이나 다른 창에 가로채여 일부만 들어갔으면 나머지만 이어서 치고, 전혀 안 들어갔으면 다시 칩니다. 최대 10회. 글자를 읽을 수 없는 앱은 입력 중 포커스가 Alpha 로 넘어가지 않았으면 성공으로 봅니다.
  • 10회 모두 실패하면 INPUT_BLOCKED → 앱이 "입력이 다른 창에 가로채여 10회 시도 후에도 들어가지 않았습니다"로 안내합니다.

조작 과정 표시: 연한 회색 + 끝나면 접힘 (사용자 요청 2026-10-12, 웹 정적 파일 — 새로고침으로 반영)

  • 대화창의 조작 과정 줄("제안: …", "✓ 실행: …" 등)을 연한 회색·작은 글씨로 보여 줍니다(.message.control).
  • 조작이 끝나면 "조작 완료 · 실행 3 · 불허 0 · 실패 0 · 12줄"처럼 요약 한 줄로 접히고, 제목 옆 화살표(›) 버튼을 누르면 펼쳐집니다(펼쳐지면 ⌄로 회전). 진행 중에는 "조작 진행 중"으로 펼쳐져 있습니다. 대화를 다시 그려도 접힘 상태가 유지됩니다(messageNode 가 control 메시지를 직접 그림).

계획 한 번 허가로 단계 전체 실행 + 계획과 다르면 새 계획표 (사용자 결정 2026-10-12)

  • 계획 창에서 계획을 허가하면 그 안의 단계들이 자동으로 진행됩니다. 각 보통 단계는 실행 직전 약 1초간 카드를 보여 주고(그 사이 불허 키·Esc·패널 버튼으로 멈출 수 있음) 자동 실행합니다. 단계마다 허가 키를 누를 필요가 없습니다.
  • 예외로 따로 허가를 받는 경우: ① Alpha 가 "확실하지 않음"으로 표시한 단계, ② 삭제처럼 되돌릴 수 없는 위험 단계(기존처럼 길게 눌러 허가). 예약 조작(미리 허가됨)은 지금처럼 전부 자동입니다.
  • 계획과 다른 상황이면 새 계획표를 세워 다시 허가받습니다(사용자 요청). 다음 중 하나가 생기면 지금 화면으로 새 계획을 제안합니다: 단계 실행 실패, 대상이 안 보여 중단 보고, 같은 동작 2회 반복, 실행 후 화면 변화 없음 2회, 계획에 없던 입력 글자, 계획 단계 수를 크게 넘김. 이미 실행한 단계는 새 계획에 다시 넣지 않도록 알려 줍니다. 새 계획도 사용자가 허가해야 진행하며, 새 계획이 3회를 넘으면 반복으로 보고 중지합니다.
  • 테스트 desktop/tests/control.test.cjs(자동 실행·대기·재계획), 데스크톱 299개 통과.

설치·업데이트

  • Windows: Setup.exe를 열고 설치를 완료한 뒤 바탕화면 또는 시작 메뉴에서 Alpha AI를 실행하세요.
  • macOS: .pkg를 실행하면 /Applications/Alpha AI.app을 설치·교체합니다. 응용 프로그램에서 새 앱을 실행하세요.
  • 기존 사용자: 메뉴 막대 또는 시스템 트레이에서 Alpha를 종료한 뒤 설치하세요. 기존 앱 삭제는 필요 없으며 로그인·설정 데이터는 보존됩니다.
  • 앱의 업데이트 안내 또는 설정 → 업데이트 확인에서 새 설치 프로그램을 열 수 있습니다. 사용자 확인 없이 자동 설치되지는 않습니다.
  • macOS 화면 권한이 거부되면 시스템 설정의 화면 기록 권한을 확인하고 앱을 다시 실행하세요.

화면 공유와 검색

운영체제 화면 권한과 화면 전송 동의가 필요합니다. 라이브 중 처음 화면과 변경된 화면은 Alpha 서버에서 분석하며 요금제 사용량이 적용됩니다. 변화 없는 화면은 재사용하지만 새 질문의 세부 확인에는 추가 분석이 필요할 수 있습니다. 라이브 종료 또는 화면 내용 포함 끄기로 전송을 중지할 수 있습니다.

원본 이미지는 대화 DB에 저장하지 않으며 질문에 사용한 설명은 대화에 남습니다. 비교용 캐시는 메모리에만 유지하고 만료·종료 시 해제합니다. 사용자가 켠 별도 녹화 저장은 유지됩니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

승인 검토에서는 검색어와 제공업체를 확인한 뒤 허가합니다. 승인 무조건 허가는 별도 확인 후 저장되며 화면 분석 기반 검색에만 적용됩니다. 검색어에는 민감 정보가 포함될 수 있으므로 승인 전에 확인하세요.

파일 찾기

유료·활성 무료체험 계정에서 허용한 폴더의 파일을 찾아 Finder·탐색기에 표시하고 삭제·이동 방법을 안내합니다. 파일 내용과 절대 경로는 전송하지 않으며 선택 파일 이름·상대 위치를 AI에 보내는 작업은 별도 동의를 받습니다. 실제 삭제·이동·실행은 자동 수행하지 않습니다. 폴더 권한은 철회할 수 있습니다.

모바일·배포 안내

휴대폰에서는 모바일 웹 대화를 이용할 수 있습니다. iPhone·Android 설치 파일, 다이나믹 아일랜드·상단 알림 연동, App Store·Google Play 출시는 아직 제공되지 않습니다.

현재 개발용 미서명 빌드입니다. macOS 정식 배포 서명·공증과 Windows 코드 서명은 없으며 Windows·Intel 실기기 설치 검증은 남아 있습니다. AI 대화에는 운영자 서버 연결이 필요합니다.

이 저장소는 앱 배포 파일과 이용 안내만 제공합니다. 서버 개발 소스와 사용자 데이터는 공개하지 않습니다.
