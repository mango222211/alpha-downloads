  • 확인: 배포 후 logs/perf.log 의 각 chat 줄 cached=<재사용 토큰 수> 와 first_token 이 줄어드는지 보면 됩니다. 문제가 있으면 환경변수 ALPHA_PREFIX_CACHE=0 으로 끌 수 있습니다. 모델 없이 검증할 수 없어 실제 효과는 배포 후 perf.log 로 확인 필요. 테스트 test_prefix_cache(경계·공통 접두·plan/keep), test_capabilities, test_engine_usage.

Alpha 내장 터미널 (사용자 요청 2026-10-13, 앱·웹)

  • 왼쪽 메뉴 터미널(키 표시 ⌘ \, Windows Ctrl+\`)로 VS Code 처럼 입력창 위에 접히는 터미널 패널이 열립니다. 일반 터미널처럼 쓰며(Mac/Linux: zsh·bash, Windows: PowerShell), 명령 사이에 현재 폴더·환경이 유지됩니다(cd` 가 다음 명령에 반영). ↑↓ 명령 기록, Ctrl+C 중단(같은 폴더에서 다시 시작), Ctrl+L 지우기, 접기·지우기·중지·닫기 버튼. 창을 닫았다 열어도 기록이 남고 앱 종료 때 셸을 정리합니다. vim 같은 전체 화면 프로그램은 지원하지 않습니다.
  • 앞으로 여러 서비스 연동에 쓰도록 window.AlphaTerminal.run(명령) 으로 다른 화면에서도 실행할 수 있게 열어 두었습니다. 웹·구버전 앱(터미널 API 없음)에서는 메뉴가 보이지 않습니다.
  • 구성: desktop/terminal.cjs(셸 관리, 문장 끝 표식으로 종료 코드·폴더 수집, 프로세스 그룹 중단), desktop/main.cjs·preload.cjs IPC alpha-terminal, web/terminal.js, 10개 언어 문구. 테스트 terminal.test.cjs 2개 + 웹 스모크(메뉴 표시/숨김, 패널 열기·실행·단축키, 설정 기본/고급).

검증된 방법 저장소 — 옳다고 확인된 생성을 서버에 저장해 모두가 빠르고 토큰 없이 재사용 (사용자 요청·결정 2026-10-13, 서버·앱·웹)

  • 결정: 대상 = 조작 계획 + 답변(도움됨 표시), V = 일반적인 데이터 표현(추가 모델 없이 정규화한 문장의 낱말·글자 n-gram 유사도, methods.similarity() 만 바꾸면 임베딩으로 교체 가능), 공유 = 사용자 허가 후(처음 한 번 Alpha 안 카드로 묻고 고급설정 '성공한 방법 공유'로 언제든 변경).
  • 저장(backend/methods.py, 표 methods·method_uses): 조작이 '목표 달성'으로 끝나면 앱이 POST /api/computer/outcome 로 계획·실행 동작을 보고 → 저장(같은 방법이면 성공 +1). 답변은 메시지 아래 도움됨 / 아님 버튼(연한 회색) → POST /api/messages/<id>/feedback → 질문·답변 저장.
  • 재사용: 조작 계획 요청(/api/computer/plan)에서 비슷한 요청(유사도 ≥ 0.85, 같은 OS)의 성공 계획이 있으면 모델 없이 그 계획(값은 지금 요청의 것으로 채움)을 돌려주고, 단계 요청(/api/computer/step)도 좌표가 필요 없는 저장 동작(앱 열기·키·입력)은 모델 없이 그대로 실행합니다(클릭 자리만 모델이 화면을 봄). 덜 비슷하면(≥ 0.5) 저장 계획을 참고 자료로 모델에 넘깁니다. 답변은 유사도 ≥ 0.9 면 저장된 답을 그대로 보내고(토큰 0) "저장된 방법으로 답변 · 성공 N회" 표시.
  • 틀리면: 저장 계획을 쓰다 계획과 다른 상황(재계획)·중단이면 그 방법의 실패 +1, 재계획은 저장 계획을 출발점으로 다시 생성하고 성공하면 새 버전(parent 연결) 으로 저장. 답변에 '아님' 이면 실패 +1. 실패가 2회 이상이고 성공보다 많으면 후보에서 내려 모델이 다시 생성합니다.
  • 개인정보: 따옴표 안 글·입력 본문은 <입력N> 자리표시자로 바꿔 저장(값 저장 안 함), 이메일·전화번호·경로·URL·6자리 이상 숫자는 <개인정보> 로 지우고 그런 방법은 본인에게만. 공유는 허가한 사용자의 개인정보 없는 방법만. 조작 과정 기록에 "검증된 방법으로 저장했습니다 / 공유됨" 줄이 남습니다.
  • 수리(runRepair)는 미리 정해진 스크립트라 저장할 생성물이 없어 제외(조작으로 하는 수리는 조작 계획으로 저장됨).
  • 테스트 test_methods(유사도·개인정보 제거·저장/공유/실패·답변 재사용·조작 계획 reuse/reference/단계 재생 10개), control.test.cjs 2개, 웹 스모크(도움됨 버튼·저장 표시·허가 카드·고급설정 토글).

화면 공유와 검색

운영체제 화면 권한과 화면 전송 동의가 필요합니다. 라이브 중 처음 화면과 변경된 화면은 Alpha 서버에서 분석하며 요금제 사용량이 적용됩니다. 변화 없는 화면은 재사용하지만 새 질문의 세부 확인에는 추가 분석이 필요할 수 있습니다. 라이브 종료 또는 화면 내용 포함 끄기로 전송을 중지할 수 있습니다.

원본 이미지는 대화 DB에 저장하지 않으며 질문에 사용한 설명은 대화에 남습니다. 비교용 캐시는 메모리에만 유지하고 만료·종료 시 해제합니다. 사용자가 켠 별도 녹화 저장은 유지됩니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

승인 검토에서는 검색어와 제공업체를 확인한 뒤 허가합니다. 승인 무조건 허가는 별도 확인 후 저장되며 화면 분석 기반 검색에만 적용됩니다. 검색어에는 민감 정보가 포함될 수 있으므로 승인 전에 확인하세요.

파일 찾기

유료·활성 무료체험 계정에서 허용한 폴더의 파일을 찾아 Finder·탐색기에 표시하고 삭제·이동 방법을 안내합니다. 파일 내용과 절대 경로는 전송하지 않으며 선택 파일 이름·상대 위치를 AI에 보내는 작업은 별도 동의를 받습니다. 실제 삭제·이동·실행은 자동 수행하지 않습니다. 폴더 권한은 철회할 수 있습니다.

모바일·배포 안내

휴대폰에서는 모바일 웹 대화를 이용할 수 있습니다. iPhone·Android 설치 파일, 다이나믹 아일랜드·상단 알림 연동, App Store·Google Play 출시는 아직 제공되지 않습니다.

현재 개발용 미서명 빌드입니다. macOS 정식 배포 서명·공증과 Windows 코드 서명은 없으며 Windows·Intel 실기기 설치 검증은 남아 있습니다. AI 대화에는 운영자 서버 연결이 필요합니다.

이 저장소는 앱 배포 파일과 이용 안내만 제공합니다. 서버 개발 소스와 사용자 데이터는 공개하지 않습니다.
