4.14.1 업데이트

4.14.0 배포 이후 쌓인 앱 쪽 변경을 묶은 업데이트입니다. 서버 쪽 변경(화면 분석 모델 교체, 128K 문맥, 하트비트 스트리밍, 행동 요청 자동 전환)은 이미 alphaaiweb.com에 적용되어 있으며, 이 앱 버전부터 아래 기능이 함께 동작합니다.

컴퓨터 조작 (Live 인터페이스)

  • 입력창의 검지 픽토그램 버튼이 앱 설정의 컴퓨터 조작 허용을 바로 켜고 끕니다(설정 창 불필요). 바뀔 때마다 현재 상태와 다음 할 일을 작은 안내로 보여 주고, 허용 중이면 픽토그램이 파란 배경 위 흰색으로 표시됩니다. 설정 창의 체크박스와 서로 동기화됩니다. 기존 '조작 모드' 강제 전환은 자동 전환(행동 요청 감지)으로 대체되었습니다.
  • 조작 시작 함수들이 데스크톱 전용 블록 안에 선언되어 있어 메인 입력에서 호출되지 않던 문제(ReferenceError)를 고쳤습니다. 이제 조작 스위치·자동 전환 모두 확인 창 → 계획 창으로 이어집니다. 화면 오류는 토스트로 표시됩니다.
  • 메인 입력창의 행동 요청("삭제해", "열어", "눌러" 등)은 답변 모델을 거치지 않습니다. 조작 허용·접근성·라이브가 모두 켜져 있으면 바로 조작 계획 창이 열리고, 아니면 코드가 고정 안내문(설정 허용·권한·라이브 켜기)을 답합니다. 질문형 문장("삭제하면 어떻게 되나요?")은 지금처럼 답변합니다. 조작 스위치는 강제 전환용으로 유지됩니다.
  • 메인 프롬프트에 컴퓨터 조작 상태 안내를 추가했습니다. 앱이 매 질문마다 조작 상태(이용 불가·설정 꺼짐·접근성 권한 없음·라이브 꺼짐·준비됨·진행 중)를 서버에 알리고, Alpha는 행동 요청에 "불가능"이라 답하는 대신 그 상태에서 조작을 시작하는 방법(설정 허용, 권한, 라이브, 조작 스위치)을 한 줄로 안내하며 실행했다고 주장하지 않습니다.
  • 조작 중에는 화면 분석 모델을 단계 사이에 내리지 않고 유지하며, 계획 1,024·단계 512토큰 출력 한도로 각 요청이 100초 제한 안에 끝나도록 했습니다.

화면 분석·라이브

  • 라이브·화면 분석의 RGB 변화 감지를 고정 격자 비교에서 쿼드트리(큰 블록 → 작은 블록) 비교로 바꿨습니다. 256px 블록을 1/16 밀도의 비스듬한 격자로 먼저 샘플링해(4px 간격과 같은 비용이지만 모든 행·열을 지나 16px 이상의 1px 선도 잡힘) 변화가 있는 블록만 128px → 설정한 격자 크기(32/64/128px)까지 쪼개고, 가장 작은 블록만 기존과 같은 기준으로 픽셀 단위 비교합니다. 샘플 위치는 프레임마다 돌아가므로 샘플 사이에 떨어진 아주 작은 변화도 다음 프레임에서 잡힙니다. 1080p 기준 변화 없음 8 ms → 0.8 ms, 타이핑 한 줄 6 ms → 1 ms(5~10배), 화면 전체 변경은 조기 종료로 동일합니다. 감지 결과(영역·여백·8개 초과/65% 이상이면 전체) 규칙은 그대로입니다.
  • 질문 시 화면 변화(RGB) 관찰 시간을 유료·무료체험 계정 최대 60초 → 300초로 확대했습니다. 긴 관찰은 촬영 간격을 늘려(300초면 약 50초 간격) 한 번에 보내는 이미지를 최대 7장으로 유지합니다. 일반 계정은 10초 그대로입니다.
  • 화면 분석(/api/vision)과 조작 계획·단계(/api/computer/plan|step)처럼 모델 작업이 긴 요청은 하트비트 스트리밍으로 응답합니다. 서버가 헤더를 먼저 보내고 20초마다 공백 1바이트를 보내다가 결과 JSON을 붙이므로, Cloudflare 무료 플랜의 100초(문서상 125초) 무응답 제한(524)에 걸리지 않습니다. 이때 오류는 본문의 {"error","status"}로 전달되며 앱·웹 클라이언트는 본문 status ≥ 400을 기존 HTTP 오류와 같게 처리합니다.

다이나믹·기타

  • 답변 생성 중 다이나믹을 접어도 답변이 계속 생성됩니다(이전에는 접으면 중단). 접힌 상태에서 답변이 끝나면 다이나믹 바의 'Alpha AI'와 단축키 사이에 종 모양 픽토그램이 나타나 흔들리고 작은 '띵' 소리가 납니다. 다이나믹을 열면 사라집니다.
  • macOS 화면 기록 권한 복구 안내의 '명령어 복사' 버튼이 실제로 복사되지 않던 문제를 고쳤습니다(라이브 창에서 앱 클립보드로 직접 복사하고, 확인 후 선택 안내로 대체).
  • '이용약관 · 개인정보' 링크를 채팅 기록 사이드바에서 설정 창 맨 아래로 옮겼습니다.
  • 앱이 서버에 웹 화면 버전을 함께 보내, 라이브 중이라 자동 갱신이 미뤄진 예전 화면에서는 "예전 버전" 안내를 받습니다. 앱을 완전히 종료 후 다시 열면 최신 화면이 적용됩니다.
  • 배포 시 다운로드 페이지(GitHub Pages)와 CHANGELOG가 자동으로 갱신됩니다.

Windows x64, macOS Apple Silicon/Intel 설치 파일은 미서명 개발용 빌드입니다.

설치·업데이트

  • Windows: Setup.exe를 열고 설치를 완료한 뒤 바탕화면 또는 시작 메뉴에서 Alpha AI를 실행하세요.
  • macOS: .pkg를 실행하면 /Applications/Alpha AI.app을 설치·교체합니다. 응용 프로그램에서 새 앱을 실행하세요.
  • 기존 사용자: 메뉴 막대 또는 시스템 트레이에서 Alpha를 종료한 뒤 설치하세요. 기존 앱 삭제는 필요 없으며 로그인·설정 데이터는 보존됩니다.
  • 앱의 업데이트 안내 또는 설정 → 업데이트 확인에서 새 설치 프로그램을 열 수 있습니다. 사용자 확인 없이 자동 설치되지는 않습니다.
  • macOS 화면 권한이 거부되면 시스템 설정의 화면 기록 권한을 확인하고 앱을 다시 실행하세요.

화면 공유와 검색

운영체제 화면 권한과 화면 전송 동의가 필요합니다. 라이브 중 처음 화면과 변경된 화면은 Alpha 서버에서 분석하며 요금제 사용량이 적용됩니다. 변화 없는 화면은 재사용하지만 새 질문의 세부 확인에는 추가 분석이 필요할 수 있습니다. 라이브 종료 또는 화면 내용 포함 끄기로 전송을 중지할 수 있습니다.

원본 이미지는 대화 DB에 저장하지 않으며 질문에 사용한 설명은 대화에 남습니다. 비교용 캐시는 메모리에만 유지하고 만료·종료 시 해제합니다. 사용자가 켠 별도 녹화 저장은 유지됩니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

승인 검토에서는 검색어와 제공업체를 확인한 뒤 허가합니다. 승인 무조건 허가는 별도 확인 후 저장되며 화면 분석 기반 검색에만 적용됩니다. 검색어에는 민감 정보가 포함될 수 있으므로 승인 전에 확인하세요.

파일 찾기

유료·활성 무료체험 계정에서 허용한 폴더의 파일을 찾아 Finder·탐색기에 표시하고 삭제·이동 방법을 안내합니다. 파일 내용과 절대 경로는 전송하지 않으며 선택 파일 이름·상대 위치를 AI에 보내는 작업은 별도 동의를 받습니다. 실제 삭제·이동·실행은 자동 수행하지 않습니다. 폴더 권한은 철회할 수 있습니다.

모바일·배포 안내

휴대폰에서는 모바일 웹 대화를 이용할 수 있습니다. iPhone·Android 설치 파일, 다이나믹 아일랜드·상단 알림 연동, App Store·Google Play 출시는 아직 제공되지 않습니다.

현재 개발용 미서명 빌드입니다. macOS 정식 배포 서명·공증과 Windows 코드 서명은 없으며 Windows·Intel 실기기 설치 검증은 남아 있습니다. AI 대화에는 운영자 서버 연결이 필요합니다.

이 저장소는 앱 배포 파일과 이용 안내만 제공합니다. 서버 개발 소스와 사용자 데이터는 공개하지 않습니다.
