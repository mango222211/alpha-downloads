v2.5 · 화면 분석 응답·오류 복사 수정

화면 전송 전 서버 연결을 확인하며, HTML 오류 페이지를 분석 결과로 읽지 않도록 수정했습니다. HTTP 상태와 중계 오류 코드를 표시하고 화면을 보내지 않는 서버 연결 확인 버튼을 제공합니다.

앱은 운영체제 클립보드로 오류 정보를 복사합니다. 브라우저·구버전 앱은 대체 복사를 시도하며, 자동 복사가 차단되면 선택된 오류 정보를 직접 복사할 수 있습니다.

질문과 첨부 파일을 보존하고, 오류 정보에 화면 이미지·인식한 글자·질문·서버 응답 원문을 포함하지 않습니다. 라이브 중 화면 전송 체크 변경도 유지됩니다.

새 버전은 앱에서 확인하고 다운로드할 수 있습니다. Windows는 설치 프로그램을 실행하고, Mac은 앱을 교체합니다.

자동 검사와 HTML 오류를 재현한 모의 화면으로 검증했습니다. Windows 실제 기기의 라이브 캡처는 확인하지 못했습니다. 공개 연결 자체가 끊긴 경우에는 운영자 서버·중계 연결 복구가 필요합니다.

설치 방법

  • Windows: 다운로드한 Setup.exe를 열고 설치 마법사를 완료하세요. 설치 후 바탕화면 또는 시작 메뉴의 Alpha AI로 실행합니다. 압축 해제나 PowerShell 명령은 필요하지 않습니다.
  • macOS: ZIP을 풀고 Alpha AI.app을 응용 프로그램 폴더에 넣으세요.
  • 업데이트: 메뉴 막대 또는 시스템 트레이에서 Alpha를 완전히 종료한 뒤 새 버전을 설치하세요. 로그인·설정 데이터는 보존합니다.
  • Windows 제거: Windows 설정 → 앱 → 설치된 앱 → Alpha AI에서 제거할 수 있습니다.

화면 공유

라이브와 화면 내용 포함을 켜고 전송 안내에 동의하면 질문할 때 최신 화면 한 장을 Alpha 서버로 보냅니다. 원본 이미지는 앱 서버의 파일·대화 DB에 저장하지 않으며 분석 설명은 대화에 남습니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

전체 화면 캡처는 데스크톱 앱에서 지원합니다. 운영자 서버 연결과 운영체제 화면 권한이 필요하며, 화면 공유를 끄면 전송이 중지됩니다.

이용 안내

앱 다운로드는 언제든 가능합니다. AI 대화는 운영자의 서버가 켜져 있을 때 이용할 수 있습니다.

현재 개발용 빌드이며 macOS 정식 배포 서명·공증과 Windows 코드 서명은 적용되지 않았습니다. 설치 파일의 구성·무결성 검사는 완료했으며, Windows 실제 기기의 설치·업데이트·제거 확인은 아직 남아 있습니다.

이 페이지는 앱 배포와 이용 안내만 제공합니다. 서버 개발 소스는 비공개로 관리됩니다.
