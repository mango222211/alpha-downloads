4.16.3 업데이트

4.16.2(2026-10-14 15:58Z 게시) 뒤에 들어간 변경입니다. 서버(재빌드)·앱·웹이 바뀝니다.

Windows: 메일은 웹 지메일, 문자는 카카오톡 (사용자 요청·결정 2026-10-15)

  • Windows 에서 메일 보내기는 항상 Chrome 의 Gmail 웹(작성 창을 열고 '보내기' 확인 후 Ctrl+Enter)으로 보냅니다. Outlook 이 없을 때 "보내기를 직접 눌러 주세요"로 끝나던 문제가 없어집니다.
  • Windows 에는 문자 앱이 없어 "문자 보내줘"는 카카오톡으로 보냅니다(카드에 "Windows는 문자를 보낼 수 없어 카카오톡으로 보냅니다" 표시).
  • 지메일 작성 창 확인 보강(Mac·Windows): '보내기' 버튼이 화면 요소로 안 잡혀도, Chrome 활성 탭이 Gmail 작성 창이면(Mac: 탭 주소·제목, Windows: 창 제목) 보냅니다. 로그인 화면이면 보내지 않습니다. Mac 은 처음 한 번 "Alpha 가 Google Chrome 을 제어" 자동화 권한을 묻습니다.
  • 내용 없이 "박근우에게 카톡 보내기"라고 하면 '카톡'이라는 글자를 보내던 문제를 고쳤습니다(보낼 글이 없으면 보내지 않고 묻습니다).

복합 작업 (사용자 요청·결정 2026-10-15)

  • "A에게 문자로 … 보내고 b@x.com에 지메일로 … 보낸 후 A에게 보낸 문자 내용을 메모에 메모해"처럼 여러 작업을 한 문장에 말하면, 연결 말(-고, -고 나서, -ㄴ 후/뒤/다음, 그리고, 그 다음)에서 나눠 각 단계를 Alpha 도구로 만듭니다(모델 0회). "보낸 문자 내용·같은 내용"은 앞 단계의 글로 채웁니다. 규칙으로 안 되는 문장은 모델이 도구를 여러 번 불러 같은 단계 카드가 됩니다.
  • 카드: 단계①·②·③을 세로로 두고 사이를 연한 회색 점선으로 잇습니다(손그림 반영). 각 단계에 대기 ○·실행 중 …·완료 ✓·실패 ✗·건너뜀 – 표시.
  • 허가(사용자 결정): 처음에 한 번 전체 허가 → 차례로 실행. 보내기·삭제가 있으면 Enter 로는 실행되지 않고 버튼으로만.
  • 실패 시(사용자 결정): 못 한 근거를 보여 주고 "다음 작업을 이어서 할까요?"를 묻습니다(그 단계에 기대는 단계는 건너뛴다고 표시). 남은 단계가 모두 그 단계에 이어지는 연쇄 작업이면 근거만 설명하고 중단합니다. 진행 상태는 서버에 저장돼 대화를 다시 열어도 이어서 할 수 있습니다.

예약 작업 (사용자 요청·결정 2026-10-15)

  • "2시 20분에 박근우에게 카톡으로 안녕 보내줘"처럼 시각 + 작업 요청은(규칙·모델 어느 쪽이든) Alpha 도구로 되면 화면 조작 계획 대신 도구 단계를 예약합니다. 복합 작업도 예약할 수 있습니다.
  • 오전/오후가 없는 1~12시(예: 2시, 3시, 12시)는 먼저 [오전 2시 20분] [오후 2시 20분] 버튼으로 묻고, 고르면 그 시각으로 다시 예약 카드를 띄웁니다(일정·알람은 기존 그대로).
  • 허가(사용자 결정): 예약할 때 카드에서 허가하면 그 시각에 Alpha 앱이 묻지 않고 실행합니다(그때 앱이 켜져 있어야 함). 화면 조작 허용 설정과 상관없이 동작하며, 결과는 시간 메뉴 > 알람 탭의 "예약 조작" 기록에 남고 취소도 거기서 합니다. 예약 단계는 서버가 다시 검증해 저장합니다.

후원자 순위 (사용자 요청·결정 2026-10-15, 서버·웹)

  • 후원 창 아래에 후원자 순위 1~10위를 보여 줍니다. 1위 방*준, 2~10위는 "-". 로그인하지 않아도 보입니다.
  • 관리자 명령(결정 "관리자 명령으로 수정"): 관리자 계정 대화창에서 /후원순위(보기) · /후원순위 2 김*수(바꾸기) · /후원순위 2 -(비우기). 바꾸기는 확인 카드를 허가해야 적용되며, 배포 없이 바로 모든 사용자에게 반영됩니다. 이름은 관리자가 적은 그대로 보입니다(가림 표시는 직접 적어 주세요).

무료체험 코드 (사용자 요청·결정 2026-10-15, 서버·웹)

  • 요금제 창 아래에 '무료체험 코드' 입력칸을 넣었습니다(로그인한 사용자). 코드를 넣고 [적용] 또는 Enter.
  • 관리자 명령(결정): /체험코드 30일 5명(만들기, 확인 카드 허가 후 ALPHA-XXXX-XXXX 형식의 추측하기 어려운 코드를 보여 줌) · /체험코드 목록(사용 현황) · /체험코드 삭제 ALPHA-XXXX-XXXX.
  • 혜택(결정 "코드마다 기간 지정"): 입력하면 그 기간만큼 무료체험(모더 수준)을 줍니다. 이미 무료체험·유료 중이면 남은 기간 뒤에 이어 붙입니다. 일반 1달 무료체험(계정당 1회) 자격과는 따로입니다.
  • 규칙(결정 "인원 한도 + 계정당 1회"): 코드마다 인원 한도, 한 계정은 같은 코드를 한 번만. 유효기간은 없고 삭제하면 끝. 무차별 대입을 막으려고 계정당 15분에 10번까지만 입력할 수 있습니다. 코드는 DB에 암호화해 저장합니다.

설치·업데이트

  • Windows: Setup.exe를 열고 설치를 완료한 뒤 바탕화면 또는 시작 메뉴에서 Alpha AI를 실행하세요.
  • macOS: .pkg를 실행하면 /Applications/Alpha AI.app을 설치·교체합니다. 응용 프로그램에서 새 앱을 실행하세요.
  • 기존 사용자: 메뉴 막대 또는 시스템 트레이에서 Alpha를 종료한 뒤 설치하세요. 기존 앱 삭제는 필요 없으며 로그인·설정 데이터는 보존됩니다.
  • 앱의 업데이트 안내 또는 설정 → 업데이트 확인에서 새 설치 프로그램을 열 수 있습니다. 사용자 확인 없이 자동 설치되지는 않습니다.
  • macOS 화면 권한이 거부되면 시스템 설정의 화면 기록 권한을 확인하고 앱을 다시 실행하세요.

화면 공유와 검색

운영체제 화면 권한과 화면 전송 동의가 필요합니다. 라이브 중 처음 화면과 변경된 화면은 Alpha 서버에서 분석하며 요금제 사용량이 적용됩니다. 변화 없는 화면은 재사용하지만 새 질문의 세부 확인에는 추가 분석이 필요할 수 있습니다. 라이브 종료 또는 화면 내용 포함 끄기로 전송을 중지할 수 있습니다.

원본 이미지는 대화 DB에 저장하지 않으며 질문에 사용한 설명은 대화에 남습니다. 비교용 캐시는 메모리에만 유지하고 만료·종료 시 해제합니다. 사용자가 켠 별도 녹화 저장은 유지됩니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

승인 검토에서는 검색어와 제공업체를 확인한 뒤 허가합니다. 승인 무조건 허가는 별도 확인 후 저장되며 화면 분석 기반 검색에만 적용됩니다. 검색어에는 민감 정보가 포함될 수 있으므로 승인 전에 확인하세요.

파일 찾기

유료·활성 무료체험 계정에서 허용한 폴더의 파일을 찾아 Finder·탐색기에 표시하고 삭제·이동 방법을 안내합니다. 파일 내용과 절대 경로는 전송하지 않으며 선택 파일 이름·상대 위치를 AI에 보내는 작업은 별도 동의를 받습니다. 실제 삭제·이동·실행은 자동 수행하지 않습니다. 폴더 권한은 철회할 수 있습니다.

모바일·배포 안내

휴대폰에서는 모바일 웹 대화를 이용할 수 있습니다. iPhone·Android 설치 파일, 다이나믹 아일랜드·상단 알림 연동, App Store·Google Play 출시는 아직 제공되지 않습니다.

현재 개발용 미서명 빌드입니다. macOS 정식 배포 서명·공증과 Windows 코드 서명은 없으며 Windows·Intel 실기기 설치 검증은 남아 있습니다. AI 대화에는 운영자 서버 연결이 필요합니다.

이 저장소는 앱 배포 파일과 이용 안내만 제공합니다. 서버 개발 소스와 사용자 데이터는 공개하지 않습니다.
