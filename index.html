Alpha 도구는 라이브 없이도 (사용자 요청 2026-10-15, 서버)

  • 라이브가 꺼져 있거나 컴퓨터 조작이 꺼져 있어도(또는 조작이 없는 Windows 앱이어도) Alpha 도구(앱 열기·크롬 검색·메모·문자·메일·파일 작업)는 그대로 씁니다. 규칙에 안 걸리는 요청은 모델이 도구를 고르고, 화면을 봐야 하는 일일 때만 예전 안내문("라이브가 꺼져 있어…")을 보냅니다.
  • 참고: Alpha 도구는 4.16.0 이상 앱에서만 동작합니다. 앱이 4.15.x이면 예전처럼 안내문이 나옵니다.

요청 인식 보강 (사용자 보고 2026-10-15, 서버)

  • 따옴표 없는 문자 요청: "연경원에게 alpha 인터페이스-문자 테스트 1 보내기", "엄마한테 집에 간다고 문자 보내줘"(→ "집에 간다"), "엄마한테 카톡으로 곧 도착 보내줘" 를 모델 없이 문자/카카오톡 카드로 띄웁니다. 방법을 말하지 않으면 문자(메시지 앱)이며, 보내기 전 위험 카드에 받는 사람·내용·방법이 보입니다. "이 파일 보내줘"처럼 파일·사진을 보내는 말은 문자로 처리하지 않습니다.
  • 조사 없는 메모 요청: "메모장에 hello world 입력해줘".
  • 열려 있는 메모에 입력(사용자 결정): "그/열린/지금 메모에 hello 입력"이면 화면 인식 없이 메모 앱(Windows: 메모장)을 앞으로 가져와 커서 위치에 붙여 넣습니다(클립보드는 원래대로 되돌림). 열린 창이 없으면 새 메모로 적습니다. Mac은 메모 앱 창에서 글 입력 위치에 커서가 있어야 본문에 들어갑니다.

GPU 메모리 보호 (MEMORY_BUDGET) (사용자 보고·결정 2026-10-15, 서버)

  • 원인: 라이브 화면 분석 뒤 답변 모델이 다시 올라온 상태에서 입력 약 6천~8천 토큰(지침+도구 목록+화면 자료+기억+대화)을 읽다가 GPU 한도를 넘었습니다.
  • 기억 요약: 질문마다 넣는 기억 참고 자료를 항목별 핵심 한 줄(첫 문장)로 줄이고 전체 약 600자로 제한했습니다(이전 2,200자). 기억 원문은 이전과 같이 서버 SSD(DB)에 그대로 저장됩니다.
  • 캐시 비우기: 시스템 지침의 접두 KV 캐시는 5분 동안 쓰지 않으면 GPU에서 비웁니다(답변 중에는 건드리지 않음).
  • 자동 재시도: 그래도 GPU 한도에 닿으면, 첫 글자가 나오기 전이면 캐시를 비우고 화면 자료와 오래된 대화(최근 4개만 남김)를 뺀 뒤 한 번 다시 답합니다. 화면 자료를 뺐다는 것을 모델에 알려 화면 내용을 추측하지 않게 합니다. 두 번째도 실패하면 예전 오류 문구를 보여 줍니다.

  • 기존 사용자: 메뉴 막대 또는 시스템 트레이에서 Alpha를 종료한 뒤 설치하세요. 기존 앱 삭제는 필요 없으며 로그인·설정 데이터는 보존됩니다.
  • 앱의 업데이트 안내 또는 설정 → 업데이트 확인에서 새 설치 프로그램을 열 수 있습니다. 사용자 확인 없이 자동 설치되지는 않습니다.

화면 공유와 검색

운영체제 화면 권한과 화면 전송 동의가 필요합니다. 라이브 중 처음 화면과 변경된 화면은 Alpha 서버에서 분석하며 요금제 사용량이 적용됩니다. 변화 없는 화면은 재사용하지만 새 질문의 세부 확인에는 추가 분석이 필요할 수 있습니다. 라이브 종료 또는 화면 내용 포함 끄기로 전송을 중지할 수 있습니다.

원본 이미지는 대화 DB에 저장하지 않으며 질문에 사용한 설명은 대화에 남습니다. 비교용 캐시는 메모리에만 유지하고 만료·종료 시 해제합니다. 사용자가 켠 별도 녹화 저장은 유지됩니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

승인 검토에서는 검색어와 제공업체를 확인한 뒤 허가합니다. 승인 무조건 허가는 별도 확인 후 저장되며 화면 분석 기반 검색에만 적용됩니다. 검색어에는 민감 정보가 포함될 수 있으므로 승인 전에 확인하세요.

파일 찾기

유료·활성 무료체험 계정에서 허용한 폴더의 파일을 찾아 Finder·탐색기에 표시하고 삭제·이동 방법을 안내합니다. 파일 내용과 절대 경로는 전송하지 않으며 선택 파일 이름·상대 위치를 AI에 보내는 작업은 별도 동의를 받습니다. 실제 삭제·이동·실행은 자동 수행하지 않습니다. 폴더 권한은 철회할 수 있습니다.

휴대폰에서는 모바일 웹 대화를 이용할 수 있습니다. iPhone·Android 설치 파일, 다이나믹 아일랜드·상단 알림 연동, App Store·Google Play 출시는 아직 제공되지 않습니다.
