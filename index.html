자동 단계 카드에서 허가 버튼·허가 키 제거 (사용자 요청 2026-10-12)

  • 계획 허가 뒤 자동으로 진행되는 단계의 카드에는 불허·중지만 남기고 "허가(Enter)" 버튼과 키 안내를 없앴습니다. 화면 포인터 안내도 "자동 실행 · 불허 · Esc 중지"로 바뀝니다. 허가 키(Enter)는 자동 단계에서는 등록하지 않습니다(createApproval.wait({noApprove})). 확실하지 않은 단계·위험 단계는 전과 같이 허가 버튼이 있습니다.

모드 개발 ↔ VS Code 연동 (사용자 결정 2026-10-12, 옵션 1: 작업 폴더 + VS Code 열기)

  • Alpha 앱의 모드 › + 만들기와 내 모드 › 새 버전 올리기에 "VS Code 로 만들기" 칸이 생깁니다(앱에서만 보임).
  • 작업 폴더 만들기: ~/AlphaMods/<모드 이름>/ 에 mod.json(이름·slug·요약·카테고리·태그·버전·호환·버전 메모), prompt.md, tool.py(예제 코드), README.md(안내 표 + --- 아래가 스토어 설명), gallery/ 틀을 만들고 바로 VS Code 로 엽니다. 이미 있는 파일은 덮어쓰지 않습니다. 새 버전 칸에서는 현재 모드의 최신 프롬프트·코드로 틀을 만듭니다.
  • VS Code 에서 열기: code 명령 → 설치된 VS Code 앱 → vscode://file/ 주소 → (없으면) Finder/탐색기 순으로 시도합니다. 별도 설치·설정이 필요 없습니다.
  • 폴더에서 불러오기: 저장한 폴더를 읽어 폼을 채웁니다(icon.png, gallery/*.png|jpg 포함, 예제 그대로인 tool.py 는 빈 도구로 취급). 올리기·정적 검사·운영자 검토는 기존 서버 흐름 그대로입니다.
  • 앱 desktop/mod-workspace.cjs(틀·읽기·목록·열기), IPC alpha-mod-workspace, preload alphaDesktop.modWorkspace; 웹 web/mods.js·style.css. 테스트 desktop/tests/mod-workspace.test.cjs(3), 데스크톱 302개 통과.

대화 요약 압축 — 백그라운드 (사용자 결정 2026-10-12, 옵션 1; 서버 + 웹)

  • 긴 대화에서 입력 한도를 넘으면 오래된 턴이 그냥 잘려 나가던 것을 바꿉니다. 누적 대화(요약 제외)가 입력 한도의 60% 를 넘으면 답변이 끝난 뒤 서버가 백그라운드에서 오래된 턴(최근 12개 메시지 = 6턴은 원문 유지)을 10줄 내외로 요약해 그 대화에 저장하고(chat_summaries, 요약 열 암호화), 다음 질문부터 "[이전 대화 요약] + 최근 원문"을 모델에 보냅니다. 두 번째 압축부터는 이전 요약에 이어 붙입니다. 요약 생성은 과금하지 않습니다.
  • 요약 생성 중 사용자가 새 질문을 보내면 요약을 즉시 취소하고 답변을 우선합니다(다음 답변 뒤 다시 시도).
  • 대화창 맨 위에 "이전 대화 요약 · N개 메시지 압축" 카드가 접힌 채 보이고, 펼쳐서 고쳐 저장하거나 지울 수 있습니다(고친 요약은 자동으로 덮어쓰지 않고 이어서 압축). 답변 뒤 25초·90초에 조용히 갱신됩니다.
  • API: GET/PATCH/DELETE /api/chats/<id>/summary, 대화 읽기 응답에 summary. 진단 로그 logs/chat-summary.log. 메모리(저장 노트)는 건드리지 않습니다.
  • 참고(검토 의견): 요청에 쓰신 "양자화"는 모델 가중치의 숫자 정밀도를 낮추는 기법이라 대화 길이와 무관하며, 여기서 구현한 것은 대화 요약 압축(rolling summary) 입니다.
  • 테스트 tests/test_chat_summary.py(3). Python 30개 모듈 전부 통과.

"메모장 열어" 가 "대상을 찾지 못했습니다" 로 끝나던 문제 (사용자 보고 2026-10-12, Windows)

  • 원인: Windows 에서 앞 앱은 프로세스 이름(Notepad)으로 보고되는데 앱은 macOS 이름(Notes)으로만 비교해 "메모장이 앞에 없다"고 보고 다시 열었고, 계획의 '메모장 열기' 단계(메모장은 이름표에 없어 다른 앱으로 취급)도 한 번 더 열었습니다. 그 뒤 모델이 "열려 있다(done)"고 하면 "모델이 직접 한 동작이 없다"는 규칙으로 거절되어 "대상을 찾지 못했습니다"로 끝났습니다.
  • 수정: macOS 이름 ↔ Windows 프로세스 이름 대응표(WINDOWS_PROCESS: Notes↔notepad, Finder↔explorer, Google Chrome↔chrome, Terminal↔WindowsTerminal/cmd/pwsh, Word↔winword 등)와 appIsFront(). 메모장·탐색기·파일 탐색기 를 같은 앱 이름표에 추가. 이미 앞에 있는 앱은 열기 단계를 건너뛰고, "<앱> 열어" 목표는 그 앱이 앞에 있거나 앱이 방금 열었으면 달성으로 끝냅니다('입력·삭제·보내기' 등이 함께 있는 목표는 전처럼 실제 동작이 있어야 함).
  • 테스트 control.test.cjs(Windows 앞 앱 일치·열기 목표 달성), 데스크톱 303개 통과.

"2분 뒤 'hello world' 이름의 알람" 이 처리되지 않던 문제 (사용자 보고 2026-10-12, 서버)

  • 원인: 알람 해석기가 "7시" 같은 시각만 찾고 "N분 뒤" 같은 상대 시간은 보지 않았습니다. 이름표도 따옴표를 모른 채 문장 나머지를 썼습니다.
  • 수정: 알람 요청에 상대 시간만 있으면 그만큼의 타이머로 잡습니다("2분 뒤 … 알람" → 2분 타이머). 따옴표로 감싼 이름('hello world')은 알람·타이머의 이름표로 그대로 씁니다. 테스트 test_timekeeping.

모델 기반 의도 추출 — 모든 메시지를 모델이 먼저 분류 (사용자 결정 2026-10-12, 옵션 2; 서버)

  • 지금까지 시간·알람·일정·예약 조작 의도는 정규식 규칙으로만 잡아 표현이 조금만 달라도 놓쳤습니다. 이제 모든 메시지를 답변 모델이 먼저 읽고 {kind, relative_seconds, date, time, label, repeat, weekdays, duration_minutes, goal, range} JSON 으로 뽑습니다(backend/intent_extract.py, 현재 시각을 함께 줌). 서버가 날짜·시각 산술과 검증(과거 조작 금지, 1년 이내, 범위 제한)을 한 뒤 기존과 같은 확인 카드(타이머·알람·일정·조회·삭제·스톱워치·예약 조작)로 올립니다. 허가 없이는 아무것도 바뀌지 않습니다.
  • 모델이 JSON 을 못 내거나 none 으로 보거나, 엔진이 바쁘거나 400자를 넘는 글이면 규칙으로 되돌아갑니다(안전망). 추출 호출은 과금하지 않습니다. 운영자 진단 logs/intent.log(종류·소요 시간만). 끄려면 서버 환경변수 ALPHA_INTENT_MODEL=0.
  • 영향: 질문마다 모델 분류 호출이 한 번 더 들어가 로컬 8B 기준 수 초가 추가됩니다(선택하신 방식의 비용).
  • 테스트 tests/test_intent_extract.py(3); 라우팅·고차생각 테스트는 규칙 경로로 고정. Python 31개 모듈 전부 통과.

설치·업데이트

  • Windows: Setup.exe를 열고 설치를 완료한 뒤 바탕화면 또는 시작 메뉴에서 Alpha AI를 실행하세요.
  • macOS: .pkg를 실행하면 /Applications/Alpha AI.app을 설치·교체합니다. 응용 프로그램에서 새 앱을 실행하세요.
  • 기존 사용자: 메뉴 막대 또는 시스템 트레이에서 Alpha를 종료한 뒤 설치하세요. 기존 앱 삭제는 필요 없으며 로그인·설정 데이터는 보존됩니다.
  • 앱의 업데이트 안내 또는 설정 → 업데이트 확인에서 새 설치 프로그램을 열 수 있습니다. 사용자 확인 없이 자동 설치되지는 않습니다.
  • macOS 화면 권한이 거부되면 시스템 설정의 화면 기록 권한을 확인하고 앱을 다시 실행하세요.

화면 공유와 검색

운영체제 화면 권한과 화면 전송 동의가 필요합니다. 라이브 중 처음 화면과 변경된 화면은 Alpha 서버에서 분석하며 요금제 사용량이 적용됩니다. 변화 없는 화면은 재사용하지만 새 질문의 세부 확인에는 추가 분석이 필요할 수 있습니다. 라이브 종료 또는 화면 내용 포함 끄기로 전송을 중지할 수 있습니다.

원본 이미지는 대화 DB에 저장하지 않으며 질문에 사용한 설명은 대화에 남습니다. 비교용 캐시는 메모리에만 유지하고 만료·종료 시 해제합니다. 사용자가 켠 별도 녹화 저장은 유지됩니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

승인 검토에서는 검색어와 제공업체를 확인한 뒤 허가합니다. 승인 무조건 허가는 별도 확인 후 저장되며 화면 분석 기반 검색에만 적용됩니다. 검색어에는 민감 정보가 포함될 수 있으므로 승인 전에 확인하세요.

파일 찾기

유료·활성 무료체험 계정에서 허용한 폴더의 파일을 찾아 Finder·탐색기에 표시하고 삭제·이동 방법을 안내합니다. 파일 내용과 절대 경로는 전송하지 않으며 선택 파일 이름·상대 위치를 AI에 보내는 작업은 별도 동의를 받습니다. 실제 삭제·이동·실행은 자동 수행하지 않습니다. 폴더 권한은 철회할 수 있습니다.

모바일·배포 안내

휴대폰에서는 모바일 웹 대화를 이용할 수 있습니다. iPhone·Android 설치 파일, 다이나믹 아일랜드·상단 알림 연동, App Store·Google Play 출시는 아직 제공되지 않습니다.

현재 개발용 미서명 빌드입니다. macOS 정식 배포 서명·공증과 Windows 코드 서명은 없으며 Windows·Intel 실기기 설치 검증은 남아 있습니다. AI 대화에는 운영자 서버 연결이 필요합니다.

이 저장소는 앱 배포 파일과 이용 안내만 제공합니다. 서버 개발 소스와 사용자 데이터는 공개하지 않습니다.
