개발용 배포 · 실행 확인 중

Mac 파일은 정식 Developer ID 서명·공증 전이어서 보안 차단이 발생할 수 있습니다. Windows 11의 시작 무반응은 진단 중입니다. 아래 Windows 파일은 오류창·로그를 추가한 1.1.1 진단용이며, 실제 기기 실행 검증은 아직 완료되지 않았습니다.

설치 방법

  • Mac: ZIP을 풀고 Alpha AI.app을 응용 프로그램 폴더에 넣으세요.
  • Windows: 폴더 전체를 압축 해제한 뒤 Start-Alpha-Diagnostics.cmd를 실행하세요. 설치 프로그램이 아니므로 설치 완료 안내는 나오지 않습니다.
  • 업데이트 전에는 메뉴 막대 또는 시스템 트레이에서 기존 Alpha를 완전히 종료하세요.

이용 안내

앱 다운로드는 언제든 가능합니다. AI 대화는 운영자의 서버가 켜져 있을 때 이용할 수 있습니다.

현재 개발용 빌드이며 macOS 정식 배포 서명·공증과 Windows 코드 서명은 적용되지 않았습니다. Windows 실제 기기 실행 검증은 별도로 필요합니다.

이 페이지는 앱 배포와 이용 안내만 제공합니다. 서버 개발 소스는 비공개로 관리됩니다.
