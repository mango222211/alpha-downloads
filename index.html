4.17.0 업데이트

새 기능

  • Linux용 Alpha가 나왔습니다(.deb·.tar.gz, x64). 대화·다이나믹·보이스챗을 쓸 수 있고, 컴퓨터 조작·라이브 화면·OS 캘린더는 다음 업데이트에서 지원합니다.
  • 보이스챗(모더·무료체험, Alpha 앱): 마이크 버튼을 누르고 말하면 Alpha가 이 기기 안에서 듣고 소리로 답하며, 말하는 동안 다이나믹 테두리가 목소리에 맞춰 빛납니다.
  • 가입할 때나 좌측 하단 프로필에서 국적을 고르면 Alpha가 그 나라 언어로 답합니다. "영어로 말해줘"처럼 다른 언어를 요청하면 그대로 따릅니다.
  • "둠 하고 싶어"라고 하면 대화 안에서 Freedoom(둠 1 호환)을 할 수 있고, 앱은 서버에 연결되지 않을 때도 기다리는 동안 Space 키로 시작할 수 있습니다.

개선

  • 웹·소개·다운로드 페이지와 앱이 사용하는 언어로 표시되고, 다운로드 페이지는 내 컴퓨터에 맞는 설치 파일을 맨 앞에 빛나는 테두리로 보여 줍니다.
  • 긴 답의 서론·본론·결론 사이에 회색 구분선이 들어가고, 모드 스토어 목록에서 설치한 모드를 바로 제거할 수 있습니다.
  • 의료 관련 질문에는 의료법 제27조 제1항에 따라 정보를 제공하지 않으며, EU 회원국에서는 EU 아동 보호 규정(GDPR 제8조 등)에 따라 당분간 소개 페이지 외의 이용이 제한됩니다.

고친 점

  • 대화 요약을 고치는 중에 자동 요약이 덮어쓰던 문제와, 연결이 불안정할 때 요청이 오래 붙잡히던 문제를 고쳤습니다.

설치·업데이트

  • Windows: Setup.exe를 열고 설치를 완료한 뒤 바탕화면 또는 시작 메뉴에서 Alpha AI를 실행하세요.
  • macOS: .pkg를 실행하면 /Applications/Alpha AI.app을 설치·교체합니다. 응용 프로그램에서 새 앱을 실행하세요.
  • 기존 사용자: 메뉴 막대 또는 시스템 트레이에서 Alpha를 종료한 뒤 설치하세요. 기존 앱 삭제는 필요 없으며 로그인·설정 데이터는 보존됩니다.
  • 앱의 업데이트 안내 또는 설정 → 업데이트 확인에서 새 설치 프로그램을 열 수 있습니다. 사용자 확인 없이 자동 설치되지는 않습니다.
  • macOS 화면 권한이 거부되면 시스템 설정의 화면 기록 권한을 확인하고 앱을 다시 실행하세요.

화면 공유와 검색

운영체제 화면 권한과 화면 전송 동의가 필요합니다. 라이브 중 처음 화면과 변경된 화면은 Alpha 서버에서 분석하며 요금제 사용량이 적용됩니다. 변화 없는 화면은 재사용하지만 새 질문의 세부 확인에는 추가 분석이 필요할 수 있습니다. 라이브 종료 또는 화면 내용 포함 끄기로 전송을 중지할 수 있습니다.

원본 이미지는 대화 DB에 저장하지 않으며 질문에 사용한 설명은 대화에 남습니다. 비교용 캐시는 메모리에만 유지하고 만료·종료 시 해제합니다. 사용자가 켠 별도 녹화 저장은 유지됩니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

승인 검토에서는 검색어와 제공업체를 확인한 뒤 허가합니다. 승인 무조건 허가는 별도 확인 후 저장되며 화면 분석 기반 검색에만 적용됩니다. 검색어에는 민감 정보가 포함될 수 있으므로 승인 전에 확인하세요.

파일 찾기

유료·활성 무료체험 계정에서 허용한 폴더의 파일을 찾아 Finder·탐색기에 표시하고 삭제·이동 방법을 안내합니다. 파일 내용과 절대 경로는 전송하지 않으며 선택 파일 이름·상대 위치를 AI에 보내는 작업은 별도 동의를 받습니다. 실제 삭제·이동·실행은 자동 수행하지 않습니다. 폴더 권한은 철회할 수 있습니다.

모바일·배포 안내

휴대폰에서는 모바일 웹 대화를 이용할 수 있습니다. iPhone·Android 설치 파일, 다이나믹 아일랜드·상단 알림 연동, App Store·Google Play 출시는 아직 제공되지 않습니다.

현재 개발용 미서명 빌드입니다. macOS 정식 배포 서명·공증과 Windows 코드 서명은 없으며 Windows·Intel 실기기 설치 검증은 남아 있습니다. AI 대화에는 운영자 서버 연결이 필요합니다.

이 저장소는 앱 배포 파일과 이용 안내만 제공합니다. 서버 개발 소스와 사용자 데이터는 공개하지 않습니다.
