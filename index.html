4.15.12 업데이트

4.15.11(2026-10-12 12:44Z 게시) 뒤에 들어간 변경입니다. 앱(Windows 알람)과 서버·웹(모더 요금제)이 모두 바뀝니다.

Windows 알람 소리가 안 울리던 문제 (사용자 보고 2026-10-12, 앱)

  • 원인: Windows 에서는 작업 스케줄러가 time-notify.ps1 을 실행해 토스트 알림을 띄우고, 소리는 토스트의 ms-winsoundevent:Notification.Looping.Alarm 에 맡겼습니다. 이 소리는 Windows 의 앱별 알림 소리 설정·집중 모드(방해 금지)·알림 소리 믹서에 따라 무음으로 처리되는 경우가 많아 토스트만 뜨고 소리가 나지 않았습니다.
  • 수정: 도우미가 직접 알람 음원을 재생합니다. C:\Windows\Media\Alarm01.wav 등 Windows 기본 알람 음원을 RingSeconds(기본 20초, 3~120초) 동안 반복 재생하고, 음원이 없으면 콘솔 비프로 대신합니다. 토스트는 화면 표시용(무음)으로 바꿨습니다. 토스트를 못 띄우는 환경에서는 예전처럼 대화상자를 띄우되, 소리는 백그라운드 작업으로 동시에 울립니다.
  • 주의: Windows 앱 업데이트가 필요합니다(도우미 파일이 앱 안에 들어 있음). 시스템 볼륨 자체가 꺼져 있으면 울리지 않습니다.
  • 테스트 time-scheduler.test.cjs(4) 포함 데스크톱 303개 통과. 스크립트 구문 검사 통과.

모더(moder) 요금제 3,990원 — 모드 스토어 접속 (사용자 결정 2026-10-12, 서버·웹)

  • 등급: 기본 990원(지금까지의 유료 혜택 그대로) / 모더 3,990원(기본 혜택 전부 + 모드 스토어 설치·사용·만들기·업로드). 1개월 무료체험은 모더 수준(모드 포함). 무료 계정·기본 요금제는 스토어 둘러보기(목록·상세)만 가능하고, 설치·켜기·만들기·새 버전 올리기는 403 안내와 함께 요금제 창이 열립니다. 제거는 누구나 가능. 체험·구독이 끝나면 설치해 둔 모드는 대화에 적용되지 않습니다(다시 모더가 되면 그대로 복구).
  • 서버: billing.py — entitlements.paid_tier(마이그레이션), 상태에 tier(basic|moder|null)·mods·prices, grant_paid(..., tier=), revoke_paid, status_of. mods.py — allowed()·PLAN_MESSAGE, 대화 적용(mods.apply)도 자격 확인. 환불 시 등급도 함께 해제.
  • 관리자 권한 명령(두 가지): ① 터미널 --grant-plan-until 날짜 --email 주소 --plan moder|basic, --revoke-plan, --plan-status. ② 관리자 계정 채팅에서 /권한 이메일 모더|기본 [YYYY-MM-DD], /권한 이메일 해제, /권한 이메일(조회), /권한(도움말). 부여·해제는 확인 카드를 허가해야 적용(POST /api/admin/plan, 관리자 전용), 모델에는 보내지 않습니다. 일반 계정이 같은 글을 보내면 보통 질문으로 처리. 결제는 처리하지 않습니다(backend/plan_command.py).
  • 웹: 요금제 창에 기본·모더 두 카드(사용 중 표시), 모드 스토어 403 → 안내 후 요금제 창(mods.js planGate), 관리자 카드 planGrantCard. README 운영자 명령 갱신.
  • 테스트 test_mods.ModPlanGateTests(3)·test_plan_command(3), Python 전 모듈 통과(test_native 는 Mac 바이너리라 Linux 실행기에서만 건너뜀).

설치·업데이트

  • Windows: Setup.exe를 열고 설치를 완료한 뒤 바탕화면 또는 시작 메뉴에서 Alpha AI를 실행하세요.
  • macOS: .pkg를 실행하면 /Applications/Alpha AI.app을 설치·교체합니다. 응용 프로그램에서 새 앱을 실행하세요.
  • 기존 사용자: 메뉴 막대 또는 시스템 트레이에서 Alpha를 종료한 뒤 설치하세요. 기존 앱 삭제는 필요 없으며 로그인·설정 데이터는 보존됩니다.
  • 앱의 업데이트 안내 또는 설정 → 업데이트 확인에서 새 설치 프로그램을 열 수 있습니다. 사용자 확인 없이 자동 설치되지는 않습니다.
  • macOS 화면 권한이 거부되면 시스템 설정의 화면 기록 권한을 확인하고 앱을 다시 실행하세요.

화면 공유와 검색

운영체제 화면 권한과 화면 전송 동의가 필요합니다. 라이브 중 처음 화면과 변경된 화면은 Alpha 서버에서 분석하며 요금제 사용량이 적용됩니다. 변화 없는 화면은 재사용하지만 새 질문의 세부 확인에는 추가 분석이 필요할 수 있습니다. 라이브 종료 또는 화면 내용 포함 끄기로 전송을 중지할 수 있습니다.

원본 이미지는 대화 DB에 저장하지 않으며 질문에 사용한 설명은 대화에 남습니다. 비교용 캐시는 메모리에만 유지하고 만료·종료 시 해제합니다. 사용자가 켠 별도 녹화 저장은 유지됩니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

승인 검토에서는 검색어와 제공업체를 확인한 뒤 허가합니다. 승인 무조건 허가는 별도 확인 후 저장되며 화면 분석 기반 검색에만 적용됩니다. 검색어에는 민감 정보가 포함될 수 있으므로 승인 전에 확인하세요.

파일 찾기

유료·활성 무료체험 계정에서 허용한 폴더의 파일을 찾아 Finder·탐색기에 표시하고 삭제·이동 방법을 안내합니다. 파일 내용과 절대 경로는 전송하지 않으며 선택 파일 이름·상대 위치를 AI에 보내는 작업은 별도 동의를 받습니다. 실제 삭제·이동·실행은 자동 수행하지 않습니다. 폴더 권한은 철회할 수 있습니다.

모바일·배포 안내

휴대폰에서는 모바일 웹 대화를 이용할 수 있습니다. iPhone·Android 설치 파일, 다이나믹 아일랜드·상단 알림 연동, App Store·Google Play 출시는 아직 제공되지 않습니다.

현재 개발용 미서명 빌드입니다. macOS 정식 배포 서명·공증과 Windows 코드 서명은 없으며 Windows·Intel 실기기 설치 검증은 남아 있습니다. AI 대화에는 운영자 서버 연결이 필요합니다.

이 저장소는 앱 배포 파일과 이용 안내만 제공합니다. 서버 개발 소스와 사용자 데이터는 공개하지 않습니다.
