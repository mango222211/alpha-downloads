계산 결과를 서버가 직접 씀 — 모델이 정답을 바꿔 쓰던 사고 (사용자 보고·결정 2026-10-14, 서버)

  • 사고: "x⁴+4x²−5 인수분해" 에서 계산기(sympy)는 (x−1)(x+1)(x²+5)·검산 통과였는데, 같은 질문에 인터넷 검색 자료 7개가 함께 들어가자 답변 모델이 (x−1)(x+1)(x²−2)(−5) 로 바꿔 썼습니다.
  • 수정 ① 계산 질문은 인터넷 검색을 하지 않습니다(검색어 제안 단계와 채팅 단계 모두). ② 결과 줄을 서버가 답 맨 위에 직접 씁니다: "인수분해 결과: (x − 1)(x + 1)(x² + 5) · 검산 통과". 모델은 풀이 과정만 설명하도록 지시가 바뀌었고, 설명은 모아 두었다가 결과와 맞지 않는 결론 줄(인수분해·전개는 sympy 로 원식과 같은지 확인, 수 계산은 결론 줄의 숫자 확인)을 지운 뒤 내보냅니다. 지운 줄이 있으면 "맨 위 결과가 검산을 통과한 값입니다" 안내가 붙습니다. 치환(t = x²) 같은 중간 단계는 지우지 않습니다. 로그인 없는 체험 대화도 같습니다.
  • ③ 숫자 소인수분해 지원("12를 소인수분해" → 2² × 3, "97 소인수분해" → 97 (소수), 10¹⁵ 이하). ④ "인수분해: a^2-b^2" 처럼 콜론을 붙인 형식도 읽습니다.
  • 테스트 test_calc 3개 추가(사고 재현: 결과 줄이 맨 앞·틀린 줄 제거·치환 단계 유지, 소인수분해·콜론, 계산 질문 검색 제안 없음).

화면 공유와 검색

운영체제 화면 권한과 화면 전송 동의가 필요합니다. 라이브 중 처음 화면과 변경된 화면은 Alpha 서버에서 분석하며 요금제 사용량이 적용됩니다. 변화 없는 화면은 재사용하지만 새 질문의 세부 확인에는 추가 분석이 필요할 수 있습니다. 라이브 종료 또는 화면 내용 포함 끄기로 전송을 중지할 수 있습니다.

원본 이미지는 대화 DB에 저장하지 않으며 질문에 사용한 설명은 대화에 남습니다. 비교용 캐시는 메모리에만 유지하고 만료·종료 시 해제합니다. 사용자가 켠 별도 녹화 저장은 유지됩니다. HTTPS 중계 서비스가 통신을 처리할 수 있습니다.

승인 검토에서는 검색어와 제공업체를 확인한 뒤 허가합니다. 승인 무조건 허가는 별도 확인 후 저장되며 화면 분석 기반 검색에만 적용됩니다. 검색어에는 민감 정보가 포함될 수 있으므로 승인 전에 확인하세요.

파일 찾기

유료·활성 무료체험 계정에서 허용한 폴더의 파일을 찾아 Finder·탐색기에 표시하고 삭제·이동 방법을 안내합니다. 파일 내용과 절대 경로는 전송하지 않으며 선택 파일 이름·상대 위치를 AI에 보내는 작업은 별도 동의를 받습니다. 실제 삭제·이동·실행은 자동 수행하지 않습니다. 폴더 권한은 철회할 수 있습니다.
